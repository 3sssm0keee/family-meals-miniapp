## 使用

这是脱敏源码交付，不能不配置就覆盖云端。先填入自己的 AppID、CLOUD_ENV、BASE_URL、后端环境变量及邀请码；不要在部署中保留 REPLACE_GUEST_CODE 等公开占位值。
后端使用 Node.js 24，在 backend 执行 npm ci；按 .env.example 创建自有配置，再执行 npm run db:generate 和 npm run build。
云托管从包根目录 Dockerfile 构建；启动会运行数据库迁移，不自动导入测试数据。密钥通过部署平台安全配置。
前端用微信开发者工具导入 miniprogram。测试脚本保留但本次没有运行数据库写入测试或部署。
manifest.json 列出脱敏后全部文件的 SHA256、修改及排除范围；本次验证为归档一致性、隐私扫描及结构检查，不是完整业务回归。
