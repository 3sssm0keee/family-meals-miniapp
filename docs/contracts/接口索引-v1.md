# API 接口索引 V1

所有路径前缀为 `/api/v1`。具体字段及响应以 openapi-v1.json 为准。

| 方法 | 路径 | operationId | 权限 | 功能 |
| --- | --- | --- | --- | --- |
| POST | `/auth/login` | `login` | PUBLIC | 微信登录 |
| POST | `/me/avatar` | `uploadAvatar` | AUTHENTICATED | 保存本人头像 |
| GET | `/me` | `getMe` | AUTHENTICATED | 当前用户 |
| PATCH | `/me` | `updateMe` | AUTHENTICATED | 修改显示名 |
| GET | `/me/families` | `listMyFamilies` | AUTHENTICATED | 我的有效家庭 |
| POST | `/families` | `createFamily` | AUTHENTICATED | 创建家庭 |
| GET | `/families/{familyId}/dishes` | `listDishes` | MEMBER | 可选菜品列表 |
| GET | `/families/{familyId}/dishes/{dishId}` | `getDish` | MEMBER | 可选菜品详情 |
| GET | `/families/{familyId}/admin/dishes` | `listAdminDishes` | ADMIN | 管理菜品列表 |
| POST | `/families/{familyId}/admin/dishes` | `createDish` | ADMIN | 新增正式菜品 |
| GET | `/families/{familyId}/admin/dishes/{dishId}/deletion-preview` | `getDishDeletionPreview` | ADMIN | 菜品删除影响预览 |
| GET | `/families/{familyId}/admin/dishes/{dishId}` | `getAdminDish` | ADMIN | 管理菜品详情 |
| PATCH | `/families/{familyId}/admin/dishes/{dishId}` | `updateDish` | ADMIN | 修改菜品 |
| DELETE | `/families/{familyId}/admin/dishes/{dishId}` | `deleteDish` | ADMIN | 物理删除菜品及规格 |
| POST | `/families/{familyId}/admin/dishes/{dishId}/variants` | `createVariant` | ADMIN | 新增版本 |
| PATCH | `/families/{familyId}/admin/dishes/{dishId}/variants/{variantId}` | `updateVariant` | ADMIN | 修改版本 |
| DELETE | `/families/{familyId}/admin/dishes/{dishId}/variants/{variantId}` | `deleteVariant` | ADMIN | 软删除版本 |
| POST | `/families/{familyId}/meal-sessions` | `ensureSession` | MEMBER | 获取或建立当天餐次 |
| GET | `/families/{familyId}/meal-sessions` | `listSessions` | MEMBER | 查询已有餐次 |
| GET | `/families/{familyId}/meal-sessions/{sessionId}` | `getSession` | MEMBER | 获取餐次详情 |
| GET | `/families/{familyId}/meal-sessions/{sessionId}/cart` | `getCart` | MEMBER | 我的购物车 |
| PUT | `/families/{familyId}/meal-sessions/{sessionId}/cart/items/{variantId}` | `addCartItem` | MEMBER | 加入一个版本 |
| DELETE | `/families/{familyId}/meal-sessions/{sessionId}/cart/items/{variantId}` | `removeCartItem` | MEMBER | 移除一个版本 |
| POST | `/families/{familyId}/meal-sessions/{sessionId}/personal-menu` | `submitMenu` | MEMBER | 提交个人选择 |
| GET | `/families/{familyId}/meal-sessions/{sessionId}/personal-menu` | `getPersonalMenu` | MEMBER | 查看我的提交 |
| POST | `/families/{familyId}/meal-sessions/{sessionId}/personal-menu/items` | `appendMenu` | MEMBER | 追加个人选择 |
| PATCH | `/families/{familyId}/meal-sessions/{sessionId}/cart/items/{variantId}/note` | `updateCartItemNote` | MEMBER | 保存本餐次本人待提交菜品备注 |
| PATCH | `/families/{familyId}/meal-sessions/{sessionId}/personal-menu/items/{variantId}/note` | `updatePersonalItemNote` | MEMBER | 更新本餐次本人单道菜备注 |
| PATCH | `/families/{familyId}/meal-sessions/{sessionId}/personal-menu/note` | `updateNote` | MEMBER | 修改已提交备注 |
| GET | `/families/{familyId}/meal-sessions/{sessionId}/menu` | `getFamilyMenu` | MEMBER | 家庭菜单 |
| GET | `/families/{familyId}/admin/meal-sessions/{sessionId}/review` | `getReview` | ADMIN | 管理员审核视图 |
| POST | `/families/{familyId}/admin/meal-sessions/{sessionId}/review` | `reviewMenu` | ADMIN | 原子批量确认或取消 |
| POST | `/families/{familyId}/admin/meal-sessions/{sessionId}/temporary-dishes` | `createTemporaryDish` | ADMIN | 新增当餐临时菜 |
| POST | `/families/{familyId}/admin/dishes/{dishId}/promote` | `promoteDish` | ADMIN | 临时菜转正式 |
| POST | `/families/{familyId}/admin/files/uploads` | `createFileUpload` | ADMIN | 申请单文件 COS 直传签名 |
| POST | `/families/{familyId}/admin/files/uploads/complete` | `completeFileUpload` | ADMIN | 校验直传图片并登记 |
| POST | `/families/{familyId}/admin/files` | `uploadFile` | ADMIN | 上传菜品图片 |
| GET | `/families/{familyId}/files/{fileId}` | `getFile` | MEMBER | 刷新图片访问地址 |
| GET | `/families/{familyId}/admin/files/cleanup-candidates` | `listFileCleanupCandidates` | ADMIN | 无菜品引用的图片候选 |
| GET | `/families/{familyId}/admin/file-cleanup-tasks/{taskId}` | `getFileCleanupTask` | ADMIN | 查看图片清理任务状态 |
| POST | `/families/{familyId}/admin/files/{fileId}/cleanup` | `requestFileCleanup` | ADMIN | 请求清理无引用图片 |
| POST | `/families/{familyId}/admin/invites` | `createInvite` | ADMIN | 生成 24 小时邀请码 |
| GET | `/families/{familyId}/admin/invites` | `listInvites` | ADMIN | 邀请码列表（不含明文） |
| DELETE | `/families/{familyId}/admin/invites/{inviteId}` | `revokeInvite` | ADMIN | 撤销邀请码 |
| POST | `/invites/redeem` | `redeemInvite` | AUTHENTICATED | 兑换邀请码 |
| GET | `/families/{familyId}/members` | `listFamilyMembers` | MEMBER | 家庭成员名册 |
| GET | `/families/{familyId}/admin/members` | `listMembers` | ADMIN | 成员列表 |
| PATCH | `/families/{familyId}/admin/members/{memberId}` | `updateMemberRole` | ADMIN | 调整成员角色 |
| DELETE | `/families/{familyId}/admin/members/{memberId}` | `removeMember` | ADMIN | 移除成员 |
| DELETE | `/families/{familyId}/members/me` | `leaveFamily` | MEMBER | 退出家庭 |
| GET | `/families/{familyId}/notification-config` | `getNotificationConfig` | MEMBER | 取得微信订阅消息配置 |
| POST | `/families/{familyId}/subscription-results` | `recordSubscriptionResult` | MEMBER | 记录客户端订阅结果 |
| GET | `/families/{familyId}/notifications` | `listMyNotifications` | MEMBER | 当前成员通知记录 |
| GET | `/families/{familyId}/admin/operations` | `listOperations` | ADMIN | 管理操作审计 |
